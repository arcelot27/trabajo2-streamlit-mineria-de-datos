# Datos de ejemplo

- `ventas_demo.csv`: muestra sintética de ventas proporcionada junto con el proyecto de referencia DataLimpia Analytics. Contiene formatos inconsistentes, valores faltantes y duplicados para probar la limpieza. No representa operaciones reales ni se carga por defecto.
- `../my_file (1).csv`: pequeña muestra de giras aportada al proyecto, usada por las pruebas del esquema especializado. Las cifras y los ajustes monetarios se conservan según el archivo; no se validan como información actual del mercado.

Estos archivos son excepciones explícitas en `.gitignore`. Los archivos propios que cargan los usuarios y las exportaciones se excluyen del repositorio.
